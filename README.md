# 🎮 NexusForge - Editor Visual de Nodos de Historia y Gameplay

> **Diseña, conecta y organiza los arcos narrativos, ramificaciones de decisiones, desafíos de gameplay y el elenco de personajes de tu videojuego.**

## ✨ Características Principales

- 🖱️ **Lienzo Infinito y Drag & Drop:** Arrastra, coloca y reubica nodos libremente en el canvas con paneo (clic derecho o rueda) y zoom fluido.
- 🎨 **Nodos Temáticos Diferenciados:**
  - 📖 **Historia / Diálogo (Púrpura):** Guión, diálogos clave y lore.
  - ⚔️ **Gameplay / Misión (Verde Neón):** Mecánicas, objetivos de nivel y recompensas.
  - 🎬 **Cinemática (Ámbar):** Escenas de corte y eventos scripted.
  - 🔀 **Elección / Branch (Rosa):** Puntos de decisión y bifurcación narrativa.
- 👥 **Gestión de Personajes y Arcos Narrativos:**
  - Fichas completas de personajes con selección de avatares, roles, motivaciones, personalidad y trasfondo.
  - **Soporte multi-personaje:** Asigna uno o más personajes participantes a cualquier escena.
  - **Filtro de arco narrativo:** Haz clic en cualquier personaje para iluminar todas sus escenas y atenuar el resto del diagrama.
- 🔗 **Conexiones Inteligentes:** Conecta puertos con curvas Bezier fluidas y elimina cables con doble clic.
- 📸 **Exportación a Imagen (PNG / JPG):** Exporta el diagrama en alta resolución (1x, 1.5x, 2x Ultra HD) con fondo oscuro o transparente para compartir con tu equipo.
- 💾 **Persistencia Local y Portabilidad:** Guardado automático en el navegador y opciones de importar/exportar proyectos completos en formato `.json`.

## 🚀 Despliegue en GitHub Pages

Este proyecto está construido con tecnología web nativa (HTML, CSS, JS), por lo que funciona al 100% en GitHub Pages sin necesidad de compilación:

1. Ve a tu repositorio en GitHub: `https://github.com/UltraChon/nexusforge`
2. Entra en **Settings** (Configuración) ➔ **Pages**.
3. En **Build and deployment** / **Source**:
   - Selecciona **Deploy from a branch**.
   - Branch: **`main`** / Folder: **`/ (root)`**.
4. Haz clic en **Save**.
5. ¡Listo! En unos segundos tu aplicación estará activa en:
   **`https://UltraChon.github.io/nexusforge/`**

## 🛠️ Ejecución Local

No requiere NodeJS ni instalación de paquetes. Simplemente abre `index.html` en cualquier navegador moderno:

```bash
# Clonar el repositorio
git clone https://github.com/UltraChon/nexusforge.git

# Abrir en el navegador
cd nexusforge
start index.html
```
